第 4 步 · App 隐私问卷（App Privacy）★ 最容易拒审的一步

ASC 左侧「App 隐私」页。问卷结果会以「隐私标签」形式展示在商店页，必须与你的隐私政策和实际代码三者一致。

本 App 的实际数据情况（已核对代码）：
· 习惯、打卡、备注：仅存本机，不上传
· 崩溃信息：写入本机文件，不自动上传
· 购买信息：由第三方内购服务 RevenueCat 接收（Apple 负责收款）
· 无广告 SDK、无埋点、不使用 IDFA
隐私政策 URL：https://你的域名/privacy.html

问卷怎么填（依 RevenueCat 官方指引）：

数据类别是否勾选说明
Purchases → Purchase History（购买历史）勾选使用 RevenueCat 必须声明
　└ 用途App Functionality + Analytics前者用于解锁权益与防欺诈，后者用于后台统计图表
　└ 是否关联身份No用的是随机匿名 ID
　└ 是否用于追踪No不做跨 App 广告追踪
Identifiers → Device ID / User ID不勾未使用 IDFA、未设自定义用户 ID
Diagnostics → Crash Data不勾崩溃日志只写本机、不上传
Financial Info / Usage Data / Location / Contacts …不勾一概不涉及
三处必须一致：代码行为 ↔ 隐私政策文字 ↔ 这份问卷。任何一处说「收集」而另一处说「不收集」，都可能被判为不准确声明。
