Streakora 习惯打卡 · 视觉规范

「按周统计、断签不清零、无压力」的 iOS 原生习惯打卡应用。本规范在配色、字体、线条、阴影上做"高级感"升级：克制留白、单一品牌强调色、发丝级分割线、分层柔影，深浅主题共用同一套令牌。

A · 周环
Weekly Ring
进度环：外圈为一周，渐变弧表示本周达标进度，末端节点为"今日"。极简、几何、最像 App Store 精品。
契合：按周统计 / 达标进度
适合：想强调"每周节奏感"
B · 升弧
Ascending Streak
上升曲线：习惯随时间向上生长，末端点最大且渐变填充，象征"坚持即成长"。动态、有生命力。
契合：长期累积 / 成长叙事
适合：想强调"越坚持越好"
C · 连续链
Infinity Loop
双环无限符号：直接隐喻"断签不清零、循环不断"。概念最强、最易记，但形似通用 infinity 图标。
契合：断签不清零 / 永续
适合：想强调"永不归零"的理念
D · 星芒徽
Aura Spark
四角星芒置于渐变圆角 tile：既是应用图标也是品牌符号，呼应"荣誉室/成就"。最"高级"、最像成品 App 图标。
契合：荣誉室 / 成就激励
适合：想强调"成就与奖赏感"
E · 周格
Weekly Dots
7 点一行、前 5 点填充：直译"本周 5/7"，与打卡网格、热力图同源。信息感最强，但识别度略依赖说明。
契合：本周网格 / 打卡密度
适合：想强调"一周七天可见"
