# 需求文档

## 1. 应用概述

### 1.1 应用名称
RockSort（每天六件事）

### 1.2 应用描述
纯本地、免登录的「每日六件事」清单工具。每天只写6件事，按「重要×紧急」自动排优先级，做完勾掉。数据只存本机，专业版靠设备内购凭证识别。

### 1.3 目标平台
iOS App

### 1.4 核心定位
出海产品，界面默认英文，支持中英文切换。

## 2. 用户与使用场景

### 2.1 目标用户
需要每日任务管理、注重隐私、不希望数据上云的用户。

### 2.2 核心使用场景
- 每天早晨规划当日6件重要事项
- 根据重要程度和紧急程度自动排序
- 完成任务后勾选，触发触觉反馈并查看进度
- 查看历史完成记录和连续打卡天数
- 进入「方法与专业版」页面学习时间管理方法并升级专业版
- 导出与导入任务数据，并通过状态指示灯查看处理状态
- 调整应用语言和主题设置
- 发送包含应用版本号的反馈邮件
- 查看包含iCloud备份说明的隐私政策和应用信息

## 3. 三条铁律

1. **每天最多6条**：当天口径为未完成条数+今日已完成条数（历史完成不占当天名额）
2. **无账号、无云同步、无后端**：所有数据仅存储在本地设备（系统级iCloud整机备份除外）
3. **专业版功能全部有门槛**：未开通则拦截并引导订阅

## 4. 数据模型

### 4.1 任务对象（Task）
- `id`：唯一标识
- `content`：任务内容（不超过100字）
- `importance`：重要程度（1-5星）
- `urgency`：紧急程度（1-5星）
- `dueDate`：截止日期（可选，YYYY-MM-DD）
- `reminder`：提醒时间（可选，HH:mm）
- `completed`：是否完成（boolean）
- `completedDate`：完成日期（YYYY-MM-DD）
- `createdAt`：创建时间戳
- `score`：优先级分数（自动计算）
- `prioLevel`：优先级等级（1-5，自动计算）

### 4.2 月计划对象（MonthlyTask）
- 字段同Task
- 归属当前月份（YYYY-MM）

### 4.3 年计划对象（YearlyTask）
- 字段同Task
- 归属当前年份（YYYY）

### 4.4 计划集对象（PlanSet）
- `period`：期间标识（月份YYYY-MM或年份YYYY）
- `tasks`：该期间的6条任务数组
- `completedAt`：归档时间戳

### 4.5 本地存储键值
- `sd.local`：主数据快照（包含所有任务、月计划、年计划、已归档数据）
- `sd.receipt`：设备内购凭证（{pro: boolean}）
- `sd.installAt`：安装时间戳
- `sd.nudged`：是否已演示过左滑手势（boolean）
- `sd.lang`：当前语言（en/zh）
- `sd.theme`：当前主题（system/light/dark）
- `sd.notif`：通知权限状态
- `sd.demoMode`：是否为演示模式（boolean，仅测试演示页面使用）

### 4.6 演示数据对象（DemoData）
- `yearlyGoals`：年度6件事固定数据数组
- `monthlyGoals`：月度6件事固定数据数组
- `dailyTasks`：每日6件事固定数据数组
- 数据结构同Task，但为静态预置，不写入sd.local

## 5. 核心算法

### 5.1 优先级计算
- **分数计算**：`calcScore(imp, urg) = Math.round((imp*0.6 + urg*0.4) * 100) / 100`
- **等级计算**：`prioLevel(score) = clamp(Math.ceil(6 - score), 1, 5)`

### 5.2 六条上限规则
- **每天口径**：未完成条数 + 今日已完成条数（历史完成不占当天名额）
- **每月/每年口径**：总条数（不管是否完成都只能6条）
- **满额处理**：隐藏快速添加行

### 5.3 进度计算
- **进度百分比**：`doneToday / (待办数 + doneToday)`
- **徽章显示**：`N/M`格式
- **全完成状态**：进度条转绿色
- **脉冲动画**：仅百分比变化时触发

### 5.4 逾期判断
- **逾期时间点**：截止日23:59:59.999之后
- **逾期天数**：`delayDays`每次渲染重新计算
- **逾期显示**：红字「逾期N天」+「去重新评估」按钮

### 5.5 连续天数计算
- **今天已打卡**：从今天起往前连续计数
- **今天未打卡**：从昨天起往前连续计数
- **断档规则**：中断即停止计数
- **最大回溯**：366天

### 5.6 排序规则
- **待办任务**：score降序，同分按createdAt降序
- **已完成任务**：completedDate降序
- **三天内/三天前划分**：以`0 <= diff < 3天`为界
- **月/年计划**：score降序，同分按createdAt升序

### 5.7 月/年自动归档
- **触发条件**：当期6条全部完成
- **归档流程**：
  1. 整组打包为PlanSet
  2. 推入monthlyDone/yearlyDone
  3. 缓冲区清空
  4. 期间+1（月进位、年+1）
  5. toast提示
- **防重复归档**：normalizePeriod在缓冲区为空时跳过已归档期间

### 5.8 7天免费体验
- **剩余天数**：`trialLeft = max(0, 7 - floor((today - installAt)/86400000))`
- **专业版判断**：`isPro() = state.pro || inTrial()`
- **所有付费门禁**：统一走isPro判断

### 5.9 付费门禁
- **拦截提示**：toast「这是专业版功能：{功能名}」
- **引导行为**：打开订阅弹层
- **付费功能列表**：分享成果、晚间复盘、明日计划、每月6件事、每年6件事、数据备份与迁移（CSV导出/导入）

- **内容精简**：移除首页内原有的专业版模块与权益卡片。

  2. 任务进度条（支持百分比、N/M徽章及全清变色）

### 6.5 任务条与手势操作
- **勾选圈**：未完成时根据优先级（lv1~lv5）显示描边；已完成时显示实底对勾。
- **紧急红点**：urgency>=4时显示。
- **逾期展示**：红字「逾期N天」+「去重新评估」按钮。
- **左滑手势**：向左滑动展开操作项，首位移>=8px定方向，松手<-80px吸附展开，支持互斥关闭。

### 6.6 添加/编辑弹层
- **任务内容**：限100字，实时计数。
- **重要程度/紧急程度**：5星选择器。
- **截止日期**：日期选择器及清除功能。
- **提醒时间**：提供9:00、12:00、18:00、22:00快捷选项。
- **明日计划开关**：开启后dueDate自动填充为次日。

### 6.7 勾选完成与触觉反馈
- **单任务完成**：点击勾选圈打卡时，触发iOS原生轻触震动反馈（Light Impact Haptic Feedback），播放撒花动效，并在400ms后写入完成状态与打卡数据。
- **全清成就庆祝**：当期待办任务全部清空时，延迟400ms弹出成就庆祝弹层，并同步触发iOS原生成功通知双重震动反馈（Success Notification Haptic Feedback）。
- **静默降级**：非iOS设备或不支持震动的环境中自动静默忽略，不产生报错。

- **页面入口**：设置页点击About进入，左上角带返回箭头回到设置页。

### 6.11 数据导出与导入管理
- **导出CSV**：导出7列标准字段（内容、重要程度、紧急程度、截止日期、提醒时间、状态、完成日期），UTF-8 BOM编码，CRLF换行。
- **导入CSV**：限制选择.csv文件，校验7列表头及字段格式，去重合并入库，重新计算score与prioLevel。
- **状态指示灯**：
  - 黄点：正在导出/导入解析中。
  - 绿点：操作成功。
  - 红点：操作失败（无数据、解析失败、格式不匹配等）。
  - 成功或失败状态维持3秒后自动淡出恢复。

## 7. 业务规则与核心逻辑

### 7.1 全局交互与视觉规范
1. **数据完全本地化**：所有任务、状态、配置全部存储在本地设备，无服务器依赖。
2. **视觉一致性**：保持卡片圆角风格，文字对比度不低于4.5:1，系统字体栈优先使用苹方、Microsoft YaHei。
3. **主题适配**：完整支持浅色与深色模式自动适配。
4. **静态化规则**：理论介绍弹窗内容全静态预置，不依赖网络请求。

### 7.2 触觉反馈触发机制
1. **单项打卡震动**：勾选任务完成时触发轻触震动反馈。
2. **全清成就震动**：当期任务全部清空弹出庆祝弹层时触发成功通知双重震动反馈。
3. **环境兼容**：非iOS或无震动支持设备静默跳过，保证业务流程畅通。

### 7.3 专业版权限与订阅规则
1. **试用与开通状态**：`isPro() = state.pro || inTrial()`，7天体验期后付费功能强制拦截。
2. **支付集成**：通过App Store内购凭证写入sd.receipt激活Pro状态。

## 8. 异常与边界情况

| 场景 | 处理规则 |
|---|---|
| 任务内容超过100字 | 实时截断并显示字数限制 |
| 每日已有6条任务（未完成+今日已完成） | 隐藏快速添加行，阻止继续新增 |
| 每月/每年已有6条任务 | 隐藏对应模块快速添加行 |
| 截止日期在当天23:59:59.999之后 | 标记为逾期，显示红字与重新评估入口 |
| 设备不支持触觉反馈 | 静默降级跳过震动，动效与数据更新正常执行 |
| 导出CSV无数据 | 状态指示灯变红，toast提示「暂无可导出数据」，3秒后恢复 |
| 导入文件为空或非CSV格式 | 状态指示灯变红，toast提示「文件格式错误或内容为空」，3秒后恢复 |
| 导入CSV表头或字段校验失败 | 状态指示灯变红，toast提示「CSV数据解析失败，请检查文件格式」，3秒后恢复 |
| 未开通专业版访问受限功能 | toast提示「这是专业版功能：{功能名}」并打开订阅弹层 |
| 设置页唤起邮件失败 | toast提示「无法打开邮件应用，请检查系统邮件设置」 |
