## 1. 已确认的问题清单

### 1.1 iOS 26 冷启动 1 秒闪退（P0 阻断，已定位）
- **现象**：TestFlight 生产包（build 50/52/53/60）打开后 splash 约 1 秒退出。崩溃签名一致：
  `thread com.meta.react.turbomodulemanager.queue → ObjCTurboModule::performVoidMethodInvocation → objc_exception_rethrow → abort`（EXC_CRASH / SIGABRT）。**仅 Release/TestFlight 复现，dev 正常**；JS `try/catch` 兜不住（abort 发生在 C++ 桥层，先于控制权回 JS）。
- **已用日志证据推翻的假设**：① RevenueCat 启动 `configure`（build 53 已延迟初始化仍崩，证伪）；② expo-linking 取初始 URL（已覆盖返回 null 仍崩，证伪）。
- **根因判断（依据官方 issue expo#44606 / reanimated#9443，尚未 100% 实证）**：`reanimated 4.2.1 + worklets 0.7.x` 在 **iOS 26 + Hermes + New Architecture** 启动期原生运行时崩溃。关键修复 `missing autorelease drain on detached worklet threads`（pr #10192）已被 backport 到 **worklets 0.10.4 / 0.11.4 / 0.12.0** 三条线——**不止 0.12.x**。注意：`executeSync → runSync` 改名发生在 0.12.0（pr #10091），导致 reanimated 4.6.0 配 0.12.x **编译不过**；但 0.10.4/0.11.4 仍保留 `executeSync`，可与老 reanimated 编译**且含修复**。
- **修复方向**：栈内升 reanimated/worklets 到含修复的配对（见 §3）。

### 1.2 reanimated / worklets 版本配对陷阱（P0，当前阻断点 — 已实测定案）
- 实测已排除的组合（在 Expo SDK 55 / RN 0.83.2 栈上，**无法同时拿到"可编译"与"含修复"**）：
  - `reanimated 4.2.1 + worklets 0.7.4`（build 60）：能编译，**冷启动仍崩**。
  - `reanimated 4.2.1 + worklets 0.8.3`：pod 校验直接拒绝（"only 0.7.x or older"）。
  - `reanimated 4.6.0 + worklets 0.12.0/0.12.1/0.12.2`：Xcode 编译报错 `no member named 'executeSync'`（**0.12.x 整条线删了 executeSync**，而 4.6.0 仍调用老符号；**4.6.0 无后续补丁版**，此路死）。
- **根因**：`executeSync → runSync` 改名在 worklets 0.12.0（pr #10091）。所以"升到 0.12.x 拿修复"在 reanimated 4.6.0 上必然失败。
- **正确解法（见 §3）**：改用 **reanimated 4.5.1 + worklets 0.10.4** —— 0.10.4 仍保留 `executeSync`（能和 4.5.1 编译），且 backport 了 #10192 autorelease drain 修复；`4.5.x ↔ 0.10.x` 是官方支持配对，pod 校验通过，且 4.5.x 支持 RN 0.83–0.87（**无需升 RN / 不动 devkit**）。

### 2.1 `src/lib/iap.ts` — RevenueCat 延迟初始化
`usePlanPrices` 增加 `enabled` 形参，**仅当 Pro/Pay 弹层打开时**才去 `import("react-native-purchases")` + `configure`，避免冷启动触碰原生模块。
```ts
// 第 80 行起
export function usePlanPrices(enabled: boolean = false): { prices: PlanPrices; ready: boolean } {
  const [prices, setPrices] = useState<PlanPrices>({ m: "", y: "", l: "" });
  const [ready, setReady] = useState(false);
  useEffect(() => {
    if (!enabled) return; // 弹层未打开：不初始化 RevenueCat，避免冷启动崩溃
    let on = true;
    (async () => {
      const rc = await getPurchases();
      if (!rc) return; // 演示态：无价格源，展示位保持占位符
      try {
        const off = await rc.getOfferings();
        // ...（原有按 RC_PRODUCT_IDS 读取 priceString 的逻辑不变）
      } catch { /* 读取失败：保持占位符 */ }
    })();
    return () => { on = false; };
  }, [enabled]);
  return { prices, ready };
}
```
