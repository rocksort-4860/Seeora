# Streakora 产品设计文档

> 版本：MVP v0.2
> 最后更新：2026-09-26

---

## 一、产品定位

### 核心理念
**只记录，不评判；鼓励连续，但不强制；所有历史永久保存，永远不会清零。**

### 目标用户
本身有意愿自律、愿意借助打卡工具，但被传统打卡App的严苛规则（断签清零）打击、中途放弃的人。

**不主动争取的人群**：内在自驱型、反感一切量化的人、动机严重不足的人、嫌操作麻烦的人。产品可以对他们有帮助，但不为他们做设计。

### 驱动方式
- **传统打卡App**：恐惧驱动——怕断签、怕清零、怕努力白费，用损失厌恶绑架用户
- **Streakora**：渴求驱动——用户想要持续积累、看见自己一路成长的痕迹。所有记录永久留存，不会因为一次失误被没收

### Slogan
- **主标语**：看见自己越来越好
- **副标题**：记录习惯，允许休息，所有坚持永久留存

### 分享海报备选文案
- 越坚持，越成长
- 越记录，越看见
- 越沉淀，越发光
- 越前行，越向好

## 二、三大操作的时间边界

严格按时间维度隔离，杜绝混淆：

| 操作 | 时间方向 | 性质 | 可操作时间 |
|---|---|---|---|
| **休息日** | 面向未来 + 当日 | 预先规划的休息 | 提前设置，最晚当天 |
| **当日打卡** | 面向当日 | 今天完成习惯 | 当天内 |
| **补签** | 面向过去 | 补救遗忘的打卡 | 仅历史日期 |

### 规则要点
- 休息日**不能事后补设**：已经过去的日期不能标记为休息日
- 补签**只能生成打卡记录**，不能标记休息日
- 休息日当天如果实际打卡，可直接覆盖休息日标记变为打卡

## 三、详细规则

### 3.1 休息日（计划休息）

- **定位**：主动规划的休息，不是事后补救漏签
- **可操作时间**：未来日期、最晚当天；历史日期禁止新增/修改
- **效果**：不计入漏签，不打断当前连续打卡
- **配额**：不限次数，不弹窗，不提示
- **覆盖逻辑**：标记休息日后当天实际打卡，可直接覆盖为打卡记录
- **已标记休息日的日期不可补签**（休息日不需要补打卡）

### 3.2 补签

- **定位**：对已过去的日期，补上忘记的打卡
- **时间锁**：过去7天内自由补签/取消，超过7天禁止补签
- **效果**：回填打卡记录，修复连续打卡链条
- **补签不能标记休息日**，只能生成打卡记录
- 补签成功后，对应圆环节点从空心变实心，相邻弧线重新连线

### 3.3 连续打卡

- **当前连续**：本轮不间断打卡 + 计划休息日的计数
- **漏签处理**：
  - 漏签1天：连续不断，继续计数
  - 连续漏签2天：连续**暂停**（不归零）
  - 恢复打卡后：连续从暂停点继续计数
- **N>1时的连续单位**：以"周期"为单位，不换算成天数。例：每3天一个节点，连续5个节点 = 连续5个周期
- **历史最长连续**：曾经达成的最高连续记录，永久保存，永不消失
- **全部打卡历史、热力图永久保留**，不存在全盘清零

### 3.4 漏签定义
普通漏签 = 当天既没打卡、也没有标记休息日、且没有补签。

## 四、习惯创建与频率设置

### 创建习惯流程
1. 输入习惯名称
2. **选择打卡频率**：滚动数字条，默认1天，最大30天（必选）
3. **选择本窗口打卡次数**：滚动数字条，默认1次，最大20次
4. 选图标/颜色（可选）
5. 完成

### 频率定义
- 频率N = 一个圆环节点代表N天
- N=1：每天一个点
- N=3：每3天一个点（圆环一圈=21天）
- N=7：每周一个点（圆环一圈=49天）
- 从习惯**创建日**开始算周期，不对齐自然周
- 不同习惯各自独立计算周期

### 窗口打卡规则
- 一个周期窗口（N天）内，任意一天打卡即完成该节点
- 窗口内已打卡后，首页显示"本周期已完成，下个周期还剩X天"
- 窗口内未打卡 → 节点空心，算漏签

### 次数定义（方案A）
- 次数 = 本窗口的目标打卡次数（如喝水8杯/天）
- **圆点实心判定**：只要本窗口打了至少一次卡，节点即实心
- 次数数字显示在节点旁（如 3/8），仅作参考
- **不因为没打够次数就算漏签、不打断连续**
- 完全没打才算空心，打断连续

## 五、可视化设计

### 5.1 螺旋圆环视图（单习惯详情页主视图）

**结构**：
- 每圈7个圆点，对应7个周期节点
- 每圈之间留间隙，区分不同7天周期
- 随时间向外螺旋生长，每圈半径递增

**节点状态**：
- **实心圆点**：本周期有打卡 / 标记了休息日
- **空心圆点**：普通漏签（无打卡、无休息日、未补签）

**连线规则**：
- 同一圈上，相邻两个实心节点之间生成平滑弧线段连接
- 实心点中间夹空心点，则两段之间不连线
- 不是强制闭合整圆，能连的地方就连上

**频率适配**：
- 一个节点 = N天（N为用户设定的频率）
- 圆环一圈 = 7个节点 = 7×N天
- 螺旋每往外一圈，代表7个新周期

### 5.2 横向时间流曲线

**坐标轴**：
- 横轴：时间（从左向右推进）
- 纵轴：累计打卡总次数（只增不减，曲线永远向上，不下降）

**节点与连线**：
- 曲线上每日一个采样节点
- 相邻实心节点之间：平滑实线
- 出现空心漏签节点：相邻段切换为小圆点组成的点状虚线
- 整条曲线从头到尾连续不断

**辅助刻度**：页面底部每5天一格浅灰色分隔，仅作阅读参考，不切割曲线

### 5.3 首页习惯卡片

- **不放圆环/曲线预览**（尺寸太小看不清）
- 显示：习惯名称、当前连续、历史最长连续
- 下方一行**最近7天迷你圆点条**：7个小圆点，打卡后今天的点变实心，相邻点之间出现极细连线
- 右侧圆形勾选按钮：当日打卡操作入口

### 5.4 螺旋圆环首次引导

- 第一次打开圆环视图时，顶部显示一行小字："每圈7个点，从你开始的那天算"
- 用户操作一次后不再显示

### 5.5 颜色规则

- **打卡**：柔和青绿色
- **计划休息日**：浅灰蓝
- **无记录/漏签**：底色，几乎不可见（不突出空白）
- **禁用红色**表达任何"失败"或"漏签"

## 六、动效规范

### 6.1 性能原则
- **历史数据固定不重绘**：已完成的过去节点和线段一旦渲染，永久不动
- **只刷新当前操作涉及的局部**：当前节点 + 相邻一小段连线

### 6.2 当日打卡动效
1. 当前节点（圆点）柔和淡入出现
2. 相邻两节点之间的新弧线段/曲线段，从0生长到完整（stroke-dashoffset动画）
3. 生长方向：横向曲线从左向右；圆环弧线顺时针
4. 时长：0.6～0.8秒
5. 打卡按钮柔和淡入填充微动画

### 6.3 补签动效
- 空心节点直接变实心
- 相邻线段从点状虚线直接切换为实线
- **不做生长动画**（补签是回填过去，不是向前生长）

### 6.4 取消打卡/取消补签
- 节点和线段直接消失，0.3秒淡出
- **不做缩回动画**

## 七、仪式感

### 第一层：轻仪式 — 圆环弧段闭合
- **触发**：当前周期节点实心，与相邻实心节点之间弧线自然连接完成
- **动效**：整圈圆环轻微呼吸（透明度1→0.85→1），1秒
- **文案**：无
- **弹窗**：无

### 第二层：中仪式 — 历史最长连续刷新
- **触发**：本次打卡后，当前连续 > 历史最长连续
- **动效**：圆环外沿光晕扩散一次，1.5秒
- **文案**：顶部居中淡入小字"新的最长连续：XX"，停留3秒自动淡褪
- **弹窗**：无，不打断操作
- **补签不触发此仪式**

### 仪式感规则
- 多层同时触发时，只触发最高层，不叠加
- 全程无音效
- 语气平静陈述，不用感叹号、不用"恭喜"
- **不设累计天数里程碑（30/66/90天等）**，不做固定节点触发

## 八、分享功能

- 所有分享素材**本机生成**，不上传用户数据到服务器
- **无App内社区**：不做关注、点赞、评论，纯单向导出图片
- 分享触发：
  - 习惯详情页固定"生成成就卡片"按钮
- 卡片内容：螺旋圆环/曲线截图 + 习惯名 + 历史最长连续 + 累计打卡周期数 + 备选文案
- 卡片底部可自定义一句话签名

---

## 九、明确不做的事

1. **不做排行榜**：不和其他用户对比
2. **不做每日奖励/积分/勋章**：不用物质诱惑绑架每天打开
3. **不做连续打卡提醒推送**：不制造焦虑
4. **不做"今日最佳""超越XX%用户"**：不攀比
5. **不在漏签时给任何提示**：不评判，沉默让记录说话
6. **不做红色表示失败**：漏签只是底色，不突出
7. **不做App内社交**：纯单机本地记录
8. **不主动争取非目标用户**：不为他们做设计

## 十、心理学依据

- **UCL 2009年研究（Philippa Lally）**：习惯养成中位数66天，个体差异18～254天。单次漏签不显著阻碍习惯养成。
- **21天法则**：源自Maxwell Maltz《心理控制术》，本是"适应新形象"的心理周期，被成功学误传为"21天养成习惯"。产品不以此设任何里程碑或节点。

## 十一、付费策略

### 模式：免费下载 + 一次性买断解锁

**免费版**：
- 最多创建5个习惯
- 所有功能全部可用：打卡、休息日、补签、螺旋圆环、横向曲线、仪式感、分享海报

**买断解锁（一次付费，永久）**：
- 不限习惯数量
- 后续大版本更新免费
- 无任何功能阉割

**付费触发时机**：
- 用户尝试创建第6个习惯时，弹出一次温和提示："免费版可创建5个习惯。买断一次，永久不限数量。"
- 不反复弹窗，不主动推销
- 用户可选择买断，也可先删掉旧习惯再新建

**定价建议**：
- 国区：18元
- 美区：$3.99

**不做**：
- 不做订阅制（月付/年付）
- 不卖主题包、勋章包
- 不做"高级数据统计"等增值收费项
