Streakora v1.0 · 功能原型说明（中英双语）

iOS 原生目标 · Apple HIG · 北美英文用户 · 买断制 $6.99 · 语言/外观/引导页/买断/抹除全部在 App 内「设置」

1. Tab 顺序与默认页

  • 底部三 Tab：历史（左）· 今天（中）· 设置（右）。打开 App 默认落在 今天。
  • 每个页面顶部只保留 🎯 Streakora 名称 + 图标 + 标语（不再有与底部 Tab 重名的大标题「今天/历史/设置」）。
  • 所有功能开关均在 App 内：设置 › 通用 = 语言（中文/EN）+ 外观（浅色/深色）；设置 › 关于 = 重看引导页；设置 › 数据安全 = 买断说明 + 导出/导入 + 抹除。

2. 今天打卡（两步完成）

  • 第 1 步打开 App，第 2 步点习惯行右侧圆形按钮即打卡，再点取消。
  • 列表底部始终有一条灰度占位引导行（虚线圆 + 灰色「添加习惯」+ 7 点示例），点一下即添加；无习惯时再加一张虚线大卡片。
  • 新建/编辑含：标题、内容/详情、图标、颜色、每周目标、提醒时间；习惯数量不限。

3. 历史页

  • 顶部累计坚持天数（本 App 真实 + 习惯内迁移）。
  • 排行榜：每个习惯坚持天数，可按「坚持天数 / 名称 / 创建时间」排序，按时间段分段徽章。
  • 保留本周网格、近 8 周、热力图。
  • 已移除「你的节奏」「为什么没有连续天数」。

4. 荣誉室（独立版块）

  • 展示从其他 App 迁移的坚持，与周统计/热力图隔离。
  • 智能位置：一旦填写了迁移内容，荣誉室自动移到历史页最上端（累计卡之前）；暂无内容时回到底部并显示占位引导行，方便首次添加。
  • 添加项：标题 / 详情 / 坚持天数 / 来源（自定义）/ 习惯类型。

5. 反竞品与留存风险

竞品吐槽Streakora
Streaks 断签归零周 5/7 即成功、无连续天数
Productive 投入后弹付费买断 $6.99、第 1 天明示
Habitify 必须注册永不注册
Coach.me 不能改 7 天前补录过去 7 天
留存待验证：「降低焦虑」是否等于「改变行为」。重点盯 W1→W2 次周留存、周达标率是否停 4/7、补录率、迁移用户 30 日留存。
